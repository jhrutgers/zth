# Project with Zth example

This example shows how to integrate Zth, assuming you have checked out the Zth repository somewhere
(like a Git submodule).

To build the example, run something like this:

```sh
mkdir build
cd build
cmake ..
cmake --build .
./hello-project
```

The script `test.sh` shows how to use Zth with a pre-installed library and built from sources.
